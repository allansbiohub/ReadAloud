# Read Aloud: host it from your phone (GitHub Pages)

1. In Files, tap the zip to unzip it.
2. At github.com, create a free account and a new public repository (any name).
3. Open the repository, tap Add file > Upload files, select all the unzipped files
   (index.html, sw.js, manifest.webmanifest and the three .png icons), and tap Commit.
4. Settings > Pages > Build from a branch > main > / (root) > Save. After a minute your address is
   https://YOURNAME.github.io/REPONAME/
5. Open that address in Safari, tap Share > Add to Home Screen.
